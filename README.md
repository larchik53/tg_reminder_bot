# Telegram Reminder Bot

## 📌 О проекте
Telegram-бот для создания напоминаний и отслеживания событий пользователя  
(задачи, дни рождения и другие события).

Проект реализован с нуля как первый практический опыт разработки  
с разбиением на модули и собственной логикой обработки времени.

---

## ⚙️ Основной функционал

- ⏰ Создание напоминаний по времени  
- 🎂 Добавление дней рождения  
- 📩 Автоматическая отправка уведомлений  
- 💾 Хранение данных пользователя  
- 📅 Работа с датами и временем  
- 📱 Интерфейс взаимодействия через Telegram  

---

## 🧠 Как это работает

Бот:

- принимает команды пользователя через Telegram  
- сохраняет события в файлы  
- периодически проверяет время  
- отправляет уведомления, когда наступает нужный момент  

---

## 🛠 Технологии

- Python  
- Telegram Bot API  
- Работа с файлами (txt)  
- Работа с датами и временем  
- Модульная архитектура  

---

## 🧱 Структура проекта

```bash
tg_reminder_bot/
│
├── main.py  точка входа, запуск бота
├── config.py  загрузка токена из .env
├── handlers.py обработка команд пользователя
├── functions.py основная логика
├── service.py вспомогательные функции
├── ui.py интерфейс (кнопки, меню)
```

## 🚀 Запуск проекта

```bash
# 1. Клонировать репозиторий
git clone https://github.com/larchik53/tg_reminder_bot.git

# 2. Перейти в папку проекта
cd tg_reminder_bot

# 3. Установить зависимости
pip install pyTelegramBotAPI python-dotenv

# 4. Создать файл .env
BOT_TOKEN=your_token_here

# 5. Запустить бота
python main.py
```

## 🔒 Безопасность

Токен бота не хранится в коде и передаётся через файл .env.
Файл .env добавлен в .gitignore и не попадает в GitHu
